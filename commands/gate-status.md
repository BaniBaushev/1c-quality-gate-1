---
description: Показать состояние гейта качества 1С — какие файлы ждут проверки
---

Покажи текущее состояние гейта качества.

Выполни:

```bash
node "${CLAUDE_PLUGIN_ROOT}/tools/gate.mjs" status
```

Затем кратко перескажи результат: взведён ли гейт, сколько файлов в охвате, какого они рода
(BSL или XML метаданных). Если гейт взведён — назови ожидаемый класс изменения по составу
файлов и объёму правок, чтобы было понятно, насколько долгим будет прогон.

Не снимай гейт этой командой — только покажи состояние.
